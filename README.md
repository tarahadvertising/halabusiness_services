# Hala Business Service (Dubai Business Setup & PRO Solutions)

A modern, high-converting corporate multi-page web application for **Hala Business Service** (Dubai, UAE), adhering strictly to the **Asset 8.svg** color identity (`#3857a6` Hala Blue & `#ffffff` Pure White).

---

## 📁 Standardized Multi-Page & Component Architecture

```
halabusiness/
├── index.html                   # Main Home Landing Page
├── services.html                # Dedicated 15-Service Showcase & Filters
├── calculator.html              # Dedicated Interactive Business Setup Cost Estimator
├── golden-visa.html             # Dedicated 10-Year Golden Visa VIP Program
├── about.html                   # Dedicated Why Choose Us & Company Background
├── faq.html                     # Dedicated Frequently Asked Questions Knowledge Base
├── contact.html                 # Dedicated Contact & Consultation Booking
├── package.json                 # Project configuration & npm scripts
├── README.md                    # Documentation & architecture guide
├── public/                      # Public Static Assets
│   ├── images/
│   │   ├── hero-skyline.jpg     # High-res Dubai skyline hero banner
│   │   └── consulting.jpg       # Corporate consultation feature visual
│   └── logos/
│       ├── logo.svg             # Reversed Hala Blue (#3857a6) vector logo
│       ├── logo-white.svg       # Transparent white horizontal vector logo
│       ├── Asset 7.svg          # Original horizontal vector logo
│       ├── Asset 8.svg          # Original 1080x1080 Hala Blue theme reference
│       └── hala logo colour s-01.svg
└── src/                         # Source Code & Components
    ├── components/
    │   ├── navbar.html          # Reusable Navbar Component
    │   └── footer.html          # Reusable Footer & Floating Actions Component
    ├── css/
    │   └── style.css            # Responsive Design System (Hala Blue & White)
    └── js/
        └── app.js               # Interactive Calculator Engine, Modals & Filters
```

---

## 🎨 Color System (Asset 8.svg Standard)
- **Primary Brand Color**: `#3857a6` (Hala Blue - Navbar, Footer, Primary CTAs, Badges)
- **Contrast / Surface**: `#ffffff` (Pure White - Typography, Crisp Cards, Vector Logos)
- **Deep Navy Accents**: `#1e3570` / `#162650` (Top bar & contrast sections)
- **Ice Blue Surfaces**: `#edf3ff` / `#f4f8fe` (Card backgrounds & icon boxes)

---

## 🚀 How to Run the Website Locally

1. **Start the local development server**:
   ```bash
   npm start
   # or
   npm run dev
   ```

2. **Open in browser**:
   Visit [http://localhost:3000](http://localhost:3000)
